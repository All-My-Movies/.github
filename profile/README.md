# All My Movies

> One named All My Movies shelf. Finish the title. Leave a cover note the next visit can read.

## How All My Movies Sits

All My Movies does not replace the player, the ripper, or the discs you already own. It sits beside them as a named home shelf for one job: which film catalog is live, which collection list still matches the cover database, and what the next person should read before the next title.

A first visit should be one short cover pass, then the same All My Movies home shelf the next day. That is enough to see if the catalog holds.

## Traffic Light

| Signal | On the All My Movies board | What you do |
|--------|----------------------|-------------|
| Green | Named shelf, short live title list | Continue the same film catalog |
| Amber | Two collections mixed on one shelf | Split the list before you add |
| Red | No title, no note, covers missing | Stop and name the shelf first |
| Clear | Handoff written, live titles few | Close All My Movies and leave the shelf |

## Open Order

1. Open the last All My Movies home shelf, not a new empty film catalog.
2. Read the collection list and the last handoff.
3. Finish one visible cover database pass inside All My Movies.
4. Write what changed, then close with fewer untitled discs than you found.
5. If the shelf feels crowded, drop anything that belongs to a different All My Movies collection.
6. Confirm All My Movies still shows covers for the titles you own.

## After a Week

A week in All My Movies is not a larger untitled disc pile. It is the same title, a shorter live shelf, and a note that still makes sense before the next disc. Take finished titles off the live set so the next visit starts on the catalog that is still open.

Other programs stay where they are. All My Movies only keeps the path back: shelf name, film catalog, cover database, handoff.

## Sign-off

- [ ] The All My Movies workspace name is short enough to scan
- [ ] Only live titles sit on the shelf
- [ ] A second person can read the shelf handoff
- [ ] The last All My Movies catalog still opens after a restart
- [ ] Finished discs are off the live All My Movies set
- [ ] The All My Movies summary still matches the cover database

## Field Note

All My Movies is easier to trust when the home shelf stays smaller than the disc folder it came from. Name the catalog, keep the live titles, finish one visible cover pass, and write what changed.
